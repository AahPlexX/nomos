# PRD Amendment 0001 — Remove Phase 0 external-review exit requirement

**Effective date:** 2026-10-08 (America/Chicago)  
**Status:** EFFECTIVE  
**Authority:** Product owner directive in the active project conversation

## Change

The Phase 0 Delivery Plan sentence in the preserved October 7, 2026 PRD says:

> Exit when five experienced external reviewers can predict component behavior from examples and the conformance drafts reveal no contradictory semantics.

The requirement for **five experienced external reviewers** is superseded and is no longer a Phase 0 exit condition.

The remaining semantic condition is retained: **conformance drafts reveal no contradictory semantics**.

For project execution, Phase 0 may exit when all Phase 0 deliverables are present and verified, the contradiction audit has no unresolved semantic contradiction, and no other explicit Phase 0 blocker remains.

## Scope and non-effects

- This amendment changes only the Phase 0 external-review exit criterion.
- It does not alter the original four PRD source fragments; those remain byte-for-byte preserved provenance.
- It does not change or renumber the 239 uppercase `MUST` / `MUST NOT` obligations because the superseded sentence is not one of those normative operators.
- It does not resolve any of the eleven PRD Open Decisions.
- External review remains optional future feedback and may still identify work, but it is not a release or phase-transition prerequisite.
